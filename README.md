# 以生成式AI建構無人機於自然環境偵察時所需之導航資訊競賽 II － 導航資料生成競賽

本專案參加 **2024 AI CUP 以生成式AI建構無人機於自然環境偵察時所需之導航資訊競賽 II**，本文件詳細紀錄如何將原始的影像生成基準模型（Baseline）優化為具備「結構感知」與「多維特徵融合」能力的深度學習架構。

核心目標在於將複雜自然環境（如河流、道路）的空拍圖，精準轉換為無人機自主導航所需的線性圖資。

**競賽時間**：2024 年 3 月 - 6 月

## 為什麼需要改良 Baseline？
原始基準模型採用標準的 **U-Net** 進行像素級生成，在處理複雜的自然環境（如河流、道路）時存在以下技術瓶頸：

1. **語義特徵模糊**：僅依賴原始 RGB 資訊。在面對樹木遮擋、河床反光或路面陰影時，模型難以區分地貌細節，導致生成的線條容易斷裂。
2. **線性結構流失**：缺乏對「線性結構」的先驗知識。生成的導航圖往往邊緣破碎，無法滿足無人機路徑規劃所需的拓撲連通性。
3. **類別權重失衡**：導航線條在全圖中佔比極小（<5%），傳統 `BCE Loss` 容易使模型傾向預測全黑（Over-fitting to background）。
4. **標準 U-Net 架構缺陷 (Architectural Bottlenecks)**：
    * **感受野限制 (Limited Receptive Field)**：固定大小的卷積核難以同時處理「寬廣河流」與「纖細小徑」在影像中劇烈的尺度變化。
    * **跳躍連接干擾 (Noisy Skip Connections)**：簡單的 Skip Connection 會將 Encoder 中的背景雜訊（如建物、無關雜物）直接傳遞至 Decoder，干擾生成品質，導致非目標區域產生偽影。

## 核心優化策略 I：多維特徵前處理與關鍵發現

本專案核心改動為引入 **傳統影像演算法輔助 (Hand-crafted Features)** 與 **多維度特徵疊加 (Feature Stacking)**，顯著強化模型對導航目標的提取能力。

### 1. 關鍵發現：解決通道資訊冗餘與噪聲 (B → Sobel)
* **技術邏輯**：將原始 RGB 中的 **B (藍色) 通道** 移除，替換為經由 **Sobel 算子** 提取的梯度特徵圖。
* **優化發現**：
    * **去冗餘**：航拍影像中 B 通道常受大氣散射影響且資訊密度低。替換為 Sobel 影像能將冗餘空間轉化為具備物理意義的結構資訊。
    * **注入結構先驗**：直接在輸入層提供邊緣特徵，等同於為模型安裝了「結構導航儀」，實驗發現這能顯著加快模型收斂速度，並在複雜陰影下保持線條的銳利度。
      
### 2. 語義強化：第四通道 (Saturation Channel)
* **技術邏輯**：融合來自 HSV 空間的 **飽和度 (S)** 通道。
* **優化效益**：河流、道路與植被在飽和度上有顯著差異。此通道能有效輔助模型過濾掉雜亂的植被干擾，鎖定核心導航語義。
  
## 核心優化策略 II：進階模型架構重構 (Model Architecture)
### 1. Squeeze-and-Excitation (SE) Block (通道注意力)
* **功能**：在卷積層後引入通道權重重標定。
* **巧思**：自動學習 4 個輸入通道的重要性。當 Sobel 或 Saturation 通道包含關鍵結構時，SE 模組會自動放大其權重，實現「特徵自適應」。
* 
### 2. ASPP (Atrous Spatial Pyramid Pooling) (多尺度感知)
* **功能**：利用多重擴張率（Dilation Rates）的空洞卷積捕捉特徵。
* **巧思**：解決標準 U-Net **感受野限制** 的痛點，使模型具備多尺度特徵提取能力，確保大河流與窄路徑均能被精準捕捉。
* 
### 3. Attention Block (空間注意力門控)
* **功能**：在 Skip Connection 處引入門控機制。
* **巧思**：利用解碼器特徵去「過濾」編碼器資訊，解決 **跳躍連接干擾** 問題，強制模型只關注與導航線相關的空間區域，排除背景雜訊。

### 4.：Deep Supervision (多尺度深監督機制)
* **功能**：於解碼器的不同層級分別輸出預測圖並計算輔助損失 (Auxiliary Loss)。
* **巧思**：確保各層級特徵圖均具備生成導航線條的能力，優化梯度傳遞，使模型在淺層就能學習到細部的邊緣特徵，強化最終結果的連通性。

## 核心優化策略 III：混合加權損失函數 (Hybrid Loss)

針對目標稀疏問題，本專案重新設計了 Loss Function 的建構邏輯：
* **BCE + Dice Loss 混合優化**：`BCE` 負責像素級穩定性，`Dice Loss` 則針對全局連通性進行優化，大幅提升線條生成的完整度。
* **邊緣加權機制**：針對預測失敗的線條邊緣給予更高的懲罰係數，確保生成的導航圖具備清晰的邊界與良好的拓撲結構。

## 實驗結果 (Performance)

本項目採用競賽官方規定的 **Mean F-measure ($F_{\beta}$)** 作為評估指標，其中參數設定為 $\beta^2 = 0.3$。

| 模型 (Model) | Mean F-measure | 提升幅度 (Improvement) |
| :--- | :---: | :---: |
| 基準模型 (Baseline) | 0.4513 | - |
| **本研究模型 (Proposed)** | **0.7331** | **+62.45%** |

### 指標說明
評分方式是在多個閾值（0-255）下計算二值化圖像的 F-score 並取平均值：
$$F\text{-score} = \frac{(1 + \beta^2) \cdot \text{Precision} \cdot \text{Recall}}{\beta^2 \cdot \text{Precision} + \text{Recall}}$$
其中 $\beta^2 = 0.3$
